# NASA Astronomy Picture of the Day

A responsive, NASA-inspired viewer for NASA's Astronomy Picture of the Day (APOD). The page loads the daily feature from NASA's public APOD API and lets you browse earlier dates.

## Run locally

Open `index.html` in a browser, or serve this directory with `python3 -m http.server` and visit `http://localhost:8000`. The APOD API requires an internet connection.

## Brand and media

The interface uses a restrained space-blue and red palette and credits NASA as the source of APOD content. It does not reproduce NASA's insignia or logotype; consult the [NASA Brand Guidelines](https://www.nasa.gov/nasa-brand-center/brand-guidelines/) before adding official marks. NASA imagery is provided by the APOD API and remains subject to NASA's [media usage guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/).
